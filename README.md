# NoMash-Library

This template should help get you started developing with Vue 3 in Vite.

## Topics 10–12 Implementation and Deployment Overview

- **Topic 10 — API Implementation:** The Topic 10 API code is included in commit `7656c91` on the `NoMash-Library` branch. This commit contains the book-count and book-list API views, together with the supporting routes, navigation, dependencies, and weather view used by the deployed application.
- **Topic 11 — Cloudflare Pages Deployment:** Topic 11 focuses on deploying the existing Vue application to Cloudflare Pages and configuring the OpenWeather environment variable. No separate source-code implementation was required for this deployment task.
- **Topic 12 — GitHub Pages Deployment:** The Topic 12 deployment configuration is included in commit `860f182` on the `main` branch. It adds the GitHub Actions deployment workflow and the corresponding Vite configuration for the `studywell-connect` application.

The deployed Topic 11 Cloudflare Pages project is available at:

<https://fit5032-2025-tianyuguo-36967572.pages.dev>
